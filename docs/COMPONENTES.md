Lámina conceptual con contenido ficticio. Las piezas de esta página describen la experiencia y sus responsabilidades visibles.

## 01 / Catálogo

Presentación prevista de modelos y productos comparables.

**En el recorrido:** Definir una necesidad.

**Responsabilidad relacionada:** Experiencia de investigación.

## 02 / Evidencia

Distinción entre información oficial, observaciones y estimaciones.

**En el recorrido:** Revisar la evidencia.

**Responsabilidad relacionada:** Comparación y contexto.

## 03 / Histórico

Diseño de una lectura temporal de cambios y condiciones.

**En el recorrido:** Comparar alternativas.

**Responsabilidad relacionada:** Evidencia temporal.

## 04 / Comparación

Recorridos previstos de selección según necesidades de uso.

**En el recorrido:** Observar los cambios.

**Responsabilidad relacionada:** Fuentes revisadas.

## Relación entre las piezas

Definir una necesidad → Revisar la evidencia → Comparar alternativas → Observar los cambios.

El recorrido permite discutir jerarquía, navegación y continuidad. La representación se simplifica a propósito y no publica los contratos internos de implementación.
