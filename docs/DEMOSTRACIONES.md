## Qué enseña esta publicación

Historia visual del recorrido previsto, con modelos ficticios y sin precios reales.

La ilustración comunica el diseño de producto; no implica una aplicación integrada o un servicio funcionando.

## Guion del caso de estudio

Este guion sirve para explicar el recorrido documentado y preparar una demostración controlada. No afirma que se haya ejecutado completo durante esta publicación.

1. **Definir una necesidad.** Observar: Presentación prevista de modelos y productos comparables.
2. **Revisar la evidencia.** Observar: Distinción entre información oficial, observaciones y estimaciones.
3. **Comparar alternativas.** Observar: Diseño de una lectura temporal de cambios y condiciones.
4. **Observar los cambios.** Observar: Recorridos previstos de selección según necesidades de uso.
